# 斗鱼每日观看自动化使用

## 当前计划

Windows 任务名：DouyuEx-DailyWatch。正式时间：每天北京时间 00:30。签到、所有粉丝牌各续 1 根、发送“嗯嗯对对”；00:40 分配四个候选房间的剩余荧光棒，停留满 40 分钟后关闭专用 Chrome。

候选顺序：6657、12306、3487376、3168536。使用 master 全量脚本，Lite 在专用配置中关闭。

## 登录和运行条件

专用配置为 automation/chrome-profile。登录一次会持久保存，只有登录过期、主动退出或斗鱼要求验证时需要重新登录。不需要每天登录；也不要清除此目录。

电脑需要在运行时开机或可被唤醒，Windows 用户保持登录，网络可用。任务以普通用户启动可见 Chrome。锁屏、系统休眠策略、浏览器升级或网站改版可能影响执行，出现异常查看日志。不要同时用其他进程打开这个专用配置。日常 Chrome 可继续使用。

## 查看任务

在 PowerShell 中运行：

    Get-ScheduledTask -TaskName 'DouyuEx-DailyWatch'
    Get-ScheduledTaskInfo -TaskName 'DouyuEx-DailyWatch'

LastTaskResult 为 0 表示脚本正常完成；非 0 需查看日志。任务处于 Running 时不要把上次结果当成本次结果。

## 文件说明

- config.json：正式参数，00:30 / 00:40 / 40 分钟。
- config.test.json：独立测试参数，不提交到 Git。本次后续补测为 testRun=true、watchOnly=true、stayMinutes=2、weightedDelayMinutes=1；仅观看 2 分钟，不发送弹幕或赠送。正式流程测试需明确改回 watchOnly=false，停留 40 分钟、第 10 分钟检查。
- runtime.local.json：本机 Node、Playwright、Chrome 的绝对路径，不提交到 Git。若 Codex 捆绑运行时升级导致路径改变，需要更新此文件。
- logs：每次执行的 JSONL、控制台日志，以及测试完成后的 test-result.json。
- state：北京时间每日的步骤执行记录和运行锁；不要为重试随意删除，避免重复送礼或弹幕。

## 正式注册或恢复

在仓库目录运行：

    & ./automation/register-task.ps1

这会把同名任务恢复为每天 00:30，不创建重复任务。

## 真实测试

运行以下命令会安排一次实际浏览器测试。watchOnly=false 时会真实签到、发送弹幕及赠送荧光棒；watchOnly=true 只观看并关闭：

    & ./automation/register-task.ps1 -TestAt ((Get-Date).AddMinutes(2))

前提是 config.test.json 和 runtime.local.json 已配置好，且当天步骤尚未执行。测试结束后 runner 会恢复每日 00:30 并写入 scheduleRestored 结果；如果异常断电导致 runner 未执行 finally，可手动运行正式注册命令恢复。绝对不要靠删除去重文件盲目重跑。

## 暂停与恢复

    Disable-ScheduledTask -TaskName 'DouyuEx-DailyWatch'
    Enable-ScheduledTask -TaskName 'DouyuEx-DailyWatch'

## 验收依据

检查 room_probe/fallback_room、sign_clicked 与 master_notices、renew_complete、barrage_response、multiplier_probe、allocation、gift_response、stay_complete、browser_closed 和任务恢复记录。签到点击只代表触发 master；其所有活动接口是否有效需结合提示核实。任何部分失败应明确记录，不能用总耗时或浏览器关闭推断全部成功。
