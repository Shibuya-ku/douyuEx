# DouyuEx 产品模块与功能梳理

基于本地 `lite` 分支、提交 `86a7f72`，脚本版本 `2026.08.07.01`；梳理日期：2026-11-17。

本文是当前项目的完整功能盘点，不是 fork 作者的原创功能列表。相对原项目的具体修改、已合入上游的贡献与旧 lite 删减，见 [Fork 修改梳理](./Fork修改梳理.md)。

本文覆盖 `src/packages` 的全部 **52 个一级模块**、主要子模块，以及 `src/require` 的 **19 个支撑组件目录**。判断依据是源码中的实际入口、界面文案、事件绑定和调用关系。本次没有登录斗鱼、执行签到/送礼等操作，也没有验证线上接口，因此“已接入”表示当前代码存在执行路径，不等于线上功能已经验证可用。

## 产品定位与用户场景

DouyuEx 是嵌入斗鱼网页的直播体验增强工具，交付形式为油猴脚本。它同时服务普通观众、经常参与弹幕和粉丝任务的用户，以及需要互动辅助的主播/房管。

| 用户场景 | 用户希望完成的事情 | 对应产品能力 |
|---|---|---|
| 安静看直播 | 减少页面干扰，调整画面与声音 | 页面净化、简洁/夜间模式、播放器增强 |
| 同时看多场直播 | 在一个页面或桌面小窗中关注多个直播 | 同屏小窗、跨平台直播流、增强画中画 |
| 参与弹幕交流 | 输入更方便、查看和保存感兴趣的消息 | 输入历史、小尾巴、收藏、右键菜单、循环发送 |
| 管理直播间互动 | 统计投票、欢迎和答复观众、管理关键词 | 直播间工具、弹幕时速、发送结果检测 |
| 维护粉丝与账号资产 | 减少签到、续牌、领奖、切号的重复操作 | 一键任务、背包、礼物工具、账号切换 |
| 查看数据和回放 | 了解主播状态、消费与观看数据，保存回放 | 数据扩展、视频下载、弹幕导出与进度提示 |

这里的“模块”有不同层级：`VideoTools` 是功能集合，`VideoSpeed` 是其中一项功能；`ExPanel` 是承载入口的界面，`Fkbuff` 等只是外站链接。统计模块数量时不能把它们都当作同等大小的独立产品。

## 用户从哪里进入

| 入口 | 承载内容 | 使用方式 |
|---|---|---|
| 礼物栏附近的精灵球 | DouyuEx 主工具条 | 点击展开；工具条支持关闭和鼠标移出后自动收起 |
| 播放器控制区与画面浮动入口 | 倍速、滤镜、截图、画面和布局控制等 | 悬浮/点击菜单操作；截图使用画面内浮动相机；菜单还可打开主工具条 |
| 直播间工具、扩展功能侧面板 | 自动互动、任务和观看开关 | 从主工具条进入；具体动作由各自按钮或开关触发 |
| 斗鱼已有界面 | 弹幕右键菜单、屏蔽设置、关注列表、背包、主播资料等 | 在原有操作位置增加选项和信息 |
| 油猴菜单 | 检查更新、重置所有设置 | 点击浏览器中的脚本管理器菜单 |
| 专属页面和后台逻辑 | 视频下载、粉丝牌日期、鱼吧访问、自动领奖等 | 进入匹配页面或在满足条件后自动执行 |

阅读状态时应区分：**已接入**是模块会初始化；**默认执行**是无需额外开启就会发生具体行为；**手动/可选**是需要操作入口或恢复已保存设置；**未接入/停用**是代码保留但当前正常入口不可达。一个模块可以同时包含多种状态。

## 产品边界与默认行为

### 不需要点击任务按钮也会发生什么

进入适配的直播间后，页面净化、弹幕显示适配、消息统计/榜单增强、输入历史、滚轮音量等会自动装配。除此之外，LevelTask 会定期领取已完成等级任务奖励，Sign_OPFOY 会定期检查固定活动的观时奖励；这些与“手动一键签到”是不同的执行路径。

自动欢迎、回复、谢礼物、禁言、抢红包和钓鱼等多数是首次关闭的开关，但会恢复已保存设置。因此“首次默认关闭”不等于每次打开页面都停用。消费统计首次隐藏；若此前已开启显示，后续会按保存设置恢复。

### 功能名称与实际效果需要对齐

| 容易产生的理解 | 当前代码应采用的产品表述 |
|---|---|
| 真实在线人数 | 第三方今日累计活跃人数，另有贵宾、弹幕人数等指标。 |
| 无限弹幕收藏 | 官方收藏之外的本地补充，不提供无限云存储或跨设备同步。 |
| 解除弹幕字数限制 | 输入框上限增加 20，服务端规则不由插件决定。 |
| 自动签到 | 主签到需点击，另外存在独立的后台领奖任务。 |
| 清空背包 | 确认后将道具赠送到当前房间，实际消耗资产。 |
| 一键续牌 | 向粉丝牌房间送出荧光棒，不只是查询牌子状态。 |
| 幻神、荧光棒变超火 | 本地视觉变化，不产生真实身份或礼物价值变化。 |
| 在线弹幕助手、红包代抢、音效增强 | 当前仓库分别提供外站入口或外部脚本联动，完整能力不都在本仓库内。 |
| 自动更新 | 主动版本检查和安装页引导，没有静默自动安装实现。 |
| 直播时间控制 | 对当前媒体缓冲进行同步、前后移动；不是完整云端回放。 |

### 从产品规划看，功能可归为三类

1. **观看体验主体**：页面净化、简洁模式、播放器增强、同屏/画中画、弹幕阅读与收藏。这部分最直接对应“让直播更好看、更好用”。
2. **互动和账号任务扩展**：签到、送礼续牌、自动回复/禁言、账号切换、活动任务。它们会产生账号动作，面向不同用户群，产品上应把动作范围和开启状态讲清楚。
3. **信息与服务入口**：主播/消费数据、抽奖发现、外站链接、版本维护与统计。其中应区分站内提供的能力、第三方数据和单纯跳转入口。

这些是对现状的产品分类，不是本次删减或改造方案。当前 `lite` 仍承载完整代码，本次只增加梳理文档。
