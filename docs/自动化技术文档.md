# 斗鱼自动化技术实现

## 入口及任务计划

- automation/daily-live-task.cjs：浏览器流程。
- automation/register-task.ps1：注册 Windows 任务 DouyuEx-DailyWatch；默认每天 00:30，TestAt 参数用于近期单次真实测试。
- automation/run-task.ps1：设置本机 Node、Playwright、Chrome 路径并启动脚本；真实测试结束后在 finally 中恢复正式 action 和每日触发器。
- automation/runtime.local.json：本机绝对运行时路径，不提交到 Git。

任务以当前 Windows 用户 Interactive / Limited 运行，不保存 Windows 密码。工作目录明确指定。并发策略 IgnoreNew，最长运行 90 分钟，允许电池运行并请求唤醒。任务启动依赖当前用户仍登录；不配置错过时立即补跑，避免在意外时刻再次发送。

## Chrome 与全量脚本

使用 launchPersistentContext、独立 automation/chrome-profile，并通过 ignoreDefaultArgs 保留扩展。该配置启用全量 DouyuEx、禁用 Lite。首次页面加载时 Tampermonkey 可能尚未就绪；等待后至多刷新一次，再等待控件。所有有副作用的步骤都在准备完成后进行。

不直接覆盖 master 的内部定时器。观看页面持续保留，倍数探测使用短生命周期页面。当前 Chrome 配置保留 Cookie，重启无需每次重新登录；斗鱼仍可能使登录态过期。

## 房间与倍数

等待页面 script 中 window.$ROOM 对象，使用括号和字符串状态解析 JSON，不执行文本代码。以 room_id 作为赠送真实房间号，避免把 6657 的别名误用于赠送；已验证其真实编号为 6979222。show_status=1 且 room_biz_all.videoLoop 不为 1 才视为实时开播。

倍数来自每个房间的粉丝牌入口及官方 vibe-lab-fansbadgejobchange iframe，校验 iframe 的 rid 与真实房间号一致，等待粉丝牌亲密度数据及“今日亲密 X 倍提升”字段。iframe 插入和导航是异步的：先使用带 rid 的 src，拿不到时轮询 frame URL，空 URL、about:blank 或缺少 rid 都不会进入分配。官方页面代码将 finalAddBuff / 100 显示为此倍数。只解析该独立字段；不扫描通用广告、不把“上限倍数”当加成。

## 签到、续牌和弹幕

签到点击 master .ex-sign；记录已触发及通知文本，不宣称所有外部子接口均成功。

续牌沿用 master 的粉丝牌列表及背包赠送接口：/member/cp/getFansBadgeList、/japi/prop/backpack/web/v5、/japi/prop/donate/mainsite/v1。为便于每笔核验，自动化逐房间发送并检查 error=0、msg=success。免费道具校验、余额校验失败即停止。全部粉丝牌各 1 根，00:40 则重读剩余数量后统一计算分配。

弹幕填写原生输入框并只点击一次。官方前端通过 WebSocket 的 chatmessage 发送消息，不能用 HTTP 回执判断成功。barrage-receipt.cjs 在页面导航前监听连接，解析 STT 二进制报文；只有观察到匹配当前账号及内容的发送报文后，同一连接的 chatres 成功响应或当前账号的同文 chatmsg 回显才算确认。其他人的同文消息、其他连接的确认、超时和错误码均不能冒充成功。监听仅在待确认期间匹配字段，不保存其他人的弹幕或登录令牌。

## 时区、去重与日志

业务日期及 00:40 时间固定使用 UTC+8；注册机系统时区已确认 China Standard Time。

automation/state 中保留每日每阶段执行记录；副作用前用排他方式创建 started 文件，完成写 completed，异常写 uncertain。已存在记录不再执行。同日测试与正式运行共用这些记录。run.lock 防止并发；异常断电遗留锁需人工确认进程及执行记录后处理，不自动删除。

每次运行生成唯一 JSONL 文件，并按北京时间每天生成 `YYYY-MM-DD.log` 中文日报，两个文件都逐条即时写盘，不覆盖旧日志。中文日报按照实际产品流程记录选房、签到、续牌、弹幕、观看奖励、倍数读取、分配、观看完成和浏览器关闭的开始、成功、失败及原因；每分钟记录观看播放状态。JSONL 保留完整结构化字段，日志不保存 Cookie 或密码。PowerShell 控制台日志与恢复结果另存同目录。

## 验证范围

tests/automation.test.cjs 覆盖房间别名、轮播排除、广告误识别、时区、分配守恒、免费背包校验、持久去重等。真实页面已验证四房间倍数读取和 Chrome 重启保持登录。长时真实运行结果见测试报告，不以纯函数测试代替真实成功。
