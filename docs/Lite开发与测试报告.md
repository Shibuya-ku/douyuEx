## 1. 交付范围

精灵球主工具条固定为“一键签到、一键续牌、扩展功能、在线弹幕助手”四项。扩展面板保留自动最高弹幕色、自动网页全屏、自动最高画质、防页签冻结、阻止 P2P 上传五个偏好和独立钓鱼区。礼物栏与播放器中的工具条入口指向同一面板；播放器底部观看菜单继续提供滤镜、画中画、音频、斗鱼同屏等观看工具。

弹幕框关闭前缀、拉高和礼物栏显示操作直接切换并保存配置。续牌数量输入、取消赠送和重置设置确认继续保留。

保留 fork 的最高弹幕色选择规则、异步等待与配置；保留无每周支持弹窗、无更新红点、无启动更新检查的行为。移除原作者在线更新入口，显示本地 Lite 版本。

已从源文件、初始化、路由和声明中清理账号/资产管理、批量礼物、抽奖、循环弹幕与自动管理、第三方统计/查弹幕/音效、跨平台取流和任意外部流输入。官方观看数据独立更新，不再等待第三方接口。在线弹幕助手按用户确认保留，只有点击时才打开外站；现有通用库 CDN 继续使用。

保留直播页内嵌鱼吧的夜间主题同步。鱼吧路由仅执行主题桥接，严格限定父窗口与官方域名，只接收日/夜模式并应用固定 CSS；未恢复 `RestoreYuba` 业务或独立鱼吧页增强。

签到保留 10 个现有有效子任务，包括鱼吧及补签、客户端、关注房间、月度活动、阅读、关注、粉丝家园、钻粉联赛、积分任务和星推。固定房间关注后取关、鱼吧补签卡使用等原有行为仍在签到范围内。粉丝牌、背包、手动发送弹幕等共用能力已从被删模块拆出，保留独立调用链。

## 2. 循环与时间行为

| 能力 | 本轮保留的行为 |
|---|---|
| 观时奖励 | 进房立即检查，之后每 5 分钟复查；每轮使用服务端任务状态及活动周期。30 分钟及之后阶段变为可领时，由后续检查处理。 |
| 等级任务 | 进房立即检查，之后每 35 秒刷新任务与领奖状态；与手动签到独立。 |
| 钓鱼 | 1.5 秒检查、既有比赛时段、服务端结束时间、已完成未收竿恢复、鱼饵不足停止；关闭后迟到响应不再开启新循环。 |
| 弹幕消息 | 40 秒心跳、退避重连、5 秒速度统计、300ms 发送比对、过期去重清理及后续开播/榜单消息。 |
| 画中画与页面 | 帧回调/备用计时、卡帧检测与条件恢复、暂停保护、关闭清理、控件迟到与重建挂接；官方观看信息每 150 秒刷新并每 5 秒轮换。 |
| 批量任务 | 房间分页、鱼吧失败重试/补签、阅读 5 次与间隔、星推 500ms、续牌 250ms、月度配置当前月→前月→后月回退。 |

观时/等级任务新增在途保护和超时释放，避免慢请求重叠或一次请求永久锁住后续检查。没有将循环改为仅签到时执行，也没有把 30 分钟写成客户端唯一领取时间。

## 3. 验证中发现并修复的问题

- 礼物栏或播放器控制栏重建后工具条消失：礼物栏不再作为整套房间初始化的前置条件；精灵球分别监听主礼物节点和延迟宿主，保留菜单节点并重新挂接，避免重复初始化和丢失子面板状态。
- 与旧版 DouyuEx 同时运行时旧节点会占位：房间初始化前清理旧精灵球、旧弹幕按钮和旧面板，再由 Lite 创建并绑定当前事件。
- 动态 DOM 迟到、仅属性发生变化或宿主被替换时监听失效：观察器等待并重新绑定，关闭时释放观察器。
- 真实页面的右键菜单懒加载导致滤镜初始化异常：支持菜单迟到并使用事件委托；滤镜重置同时恢复镜像和亮度等内部状态。
- 元数据获取中的空 URL 判断原为恒真条件：改为同时排除空字符串与空值，避免取流失败后创建无效隐藏播放器。
- 关注列表请求失败、慢请求和旧容器响应会破坏列表：在途去重，成功后才替换自有条目，失败保留原列表并支持重试。
- 续牌计数和部分库存处理：修复统计，库存不足全量续牌时按顺序完成可支持的份额；输入 0 仍按平均数取整。
- 签到分页和超时失败：某页失败继续后续页；粉丝牌请求独立化；各任务失败隔离；缺失 CSRF 头或超时能够结束。
- 回放 DOM 迟到、视频切换与失败导出：等待 Shadow DOM，丢弃旧视频响应，空密度结果不产生 NaN，异常分页/导出可结束并重试。
- GIF、全景和小窗退出清理：松开、失焦、退出时停止相关帧任务、轨道或事件，避免关闭后继续采集/恢复。
- 夜间主题跨子域适配：通过限定来源的消息同步嵌入鱼吧主题，覆盖迟到、重载、替换和保存偏好恢复。

## 6. 复现命令

先按 README 安装 Node.js 与构建依赖：

```powershell
npm ci
npm run build
npm test
```

浏览器测试需额外可用的 Playwright 和 Chromium/Edge。可安装本地测试工具后运行：

```powershell
npm install --no-save --package-lock=false playwright
npx playwright install chromium
npm run test:browser
node tests/live-smoke.cjs
```

已有 Playwright/Edge 时，可用 `PLAYWRIGHT_MODULE` 指向 Playwright 模块目录，`BROWSER_EXECUTABLE` 指向浏览器执行文件。`tests/live-smoke.cjs` 需要访问斗鱼公开页面；它创建独立未登录上下文、使用临时 GM/网络替身，不安装用户脚本，也不借用用户账号。

## 7. 测试边界

未使用真实登录账号执行签到、补签、观时/等级领奖、续牌赠送、关注/取关或钓鱼消耗；这些行为验证到请求、状态、顺序、次数和错误处理层。30 分钟测试使用可控时间和服务端状态，不能代替真实活动资格验证。

媒体轨道、GIF 编码器、Three 渲染与导出下载在模块测试中使用替身。真实页面冒烟确认当前斗鱼页面和播放 DOM 的兼容性，不能据此宣称真实 GIF 编码、画中画/多路音视频、回放签名/下载、跨浏览器及长时稳定性均已完成线上测试。

本次执行范围不含推送、发布、安装到用户浏览器或修改登录 Cookie。原有用户配置按保留功能继续使用，已删除功能的旧值不再触发行为。
